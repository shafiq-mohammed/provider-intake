# T-001: App skeleton, settings, JSON error envelope, health check

Status: done
Depends on: none

## Goal
An operator can start the service, hit `GET /healthz`, and every error the framework or the app produces comes back as the same JSON envelope with a 4xx status.

## Scope
In:
- `src/app/settings.py`: `Settings` model with defaults and `Settings.from_env()`.
- `src/app/errors.py`: `ApiError`, `error_response()`, `register_error_handlers()`.
- `src/app/main.py`: `create_app(settings=None)` factory, `GET /healthz`, module-level `app`.
- Handlers mapping `ApiError`, pydantic `RequestValidationError` (422) and Starlette `HTTPException` (404/405/other) into the envelope.
- `tests/test_T-001_skeleton.py`.
Out:
- Any document, upload, OCR, or extraction endpoint (T-002+).
- The `repository`, `ocr_engine`, `field_extractor`, `clock` keyword arguments of `create_app` (added by later tickets; only `settings` exists here).
- A catch-all handler for unexpected exceptions (bugs still 500; see SPEC A16).
- Reading `.env` files; only process environment via `from_env`.

## Interface (copied from docs/SPEC.md so the ticket is self-contained)

```python
# src/app/settings.py
from collections.abc import Mapping
from typing import Literal
from pydantic import BaseModel, ConfigDict

class Settings(BaseModel):
    model_config = ConfigDict(frozen=True)
    max_upload_bytes: int = 10 * 1024 * 1024
    allowed_content_types: tuple[str, ...] = ("application/pdf", "image/jpeg", "image/png")
    min_pdf_text_chars: int = 20
    ocr_backend: Literal["fake", "anthropic"] = "fake"
    extractor_backend: Literal["fake", "anthropic"] = "fake"
    anthropic_api_key: str | None = None
    anthropic_model: str = "claude-sonnet-5"

    @classmethod
    def from_env(cls, env: Mapping[str, str] | None = None) -> "Settings":
        """env defaults to os.environ. Unset keys keep their defaults.
        APP_MAX_UPLOAD_BYTES -> max_upload_bytes (int)
        APP_MIN_PDF_TEXT_CHARS -> min_pdf_text_chars (int)
        APP_OCR_BACKEND -> ocr_backend
        APP_EXTRACTOR_BACKEND -> extractor_backend
        ANTHROPIC_API_KEY -> anthropic_api_key
        APP_ANTHROPIC_MODEL -> anthropic_model
        allowed_content_types is not configurable from the environment.
        Invalid values raise pydantic.ValidationError."""
```

```python
# src/app/errors.py
from typing import Any
from fastapi import FastAPI
from fastapi.responses import JSONResponse

class ApiError(Exception):
    def __init__(
        self, status_code: int, code: str, message: str, details: dict[str, Any] | None = None
    ) -> None: ...
    status_code: int
    code: str
    message: str
    details: dict[str, Any]   # {} when not given

def error_response(
    status_code: int, code: str, message: str, details: dict[str, Any] | None = None
) -> JSONResponse:
    """Body: {"error": {"code": code, "message": message, "details": details or {}}}"""

def register_error_handlers(app: FastAPI) -> None:
    """Registers handlers for ApiError, RequestValidationError (422 validation_error,
    details {"errors": safe_validation_errors(exc)}) and Starlette HTTPException
    (404 not_found, 405 method_not_allowed, otherwise http_error; message = exc.detail)."""
```

```python
# src/app/main.py
from collections.abc import Callable
from datetime import date
from fastapi import FastAPI

def create_app(
    settings: Settings | None = None,
    *,
    repository: DocumentRepository | None = None,     # T-002
    ocr_engine: OcrEngine | None = None,              # T-003
    field_extractor: FieldExtractor | None = None,    # T-004
    clock: Callable[[], date] | None = None,          # T-005
) -> FastAPI:
    """settings None -> Settings() (defaults, NOT the environment).
    Stores settings on app.state.settings, registers error handlers, includes routers.
    Keyword arguments are introduced by the ticket noted; T-001 implements only `settings`."""

app = create_app(Settings.from_env())   # the only place the environment is read
```

Envelope, always: `{"error": {"code": "<snake_case>", "message": "<human readable>", "details": {}}}`.
`details` is always a JSON object (`{}` when there is nothing to add).

| Trigger                                     | Status  | code                 | details                                      |
|---------------------------------------------|---------|----------------------|----------------------------------------------|
| `ApiError` raised anywhere                  | its own | its own              | its own (or `{}`)                            |
| `fastapi.exceptions.RequestValidationError` | 422     | `validation_error`   | `{"errors": safe_validation_errors(exc)}` |
| Starlette `HTTPException` (unknown route)   | 404     | `not_found`          | `{}`                                         |
| Starlette `HTTPException` (bad method)      | 405     | `method_not_allowed` | `{}`                                         |
| Starlette `HTTPException` (other)           | its own | `http_error`         | `{}`                                         |

Endpoints (T-001):

| Method | Path       | Response                          |
|--------|------------|-----------------------------------|
| GET    | /healthz   | 200 `{"status": "ok"}`            |
| any    | unknown    | 404 envelope, code `not_found`    |

## Acceptance criteria
AC1. Given an app from `create_app()` When a client calls `GET /healthz` Then the response is 200 with body exactly `{"status": "ok"}` and `app.state.settings` equals `Settings()`.
AC2. Given an app from `create_app()` When a client requests an unknown path such as `GET /nope` Then the response is 404 with body `{"error": {"code": "not_found", "message": <non-empty str>, "details": {}}}`, and `POST /healthz` returns 405 with code `method_not_allowed` in the same envelope.
AC3. Given an app from `create_app()` on which the test has registered a throwaway `POST /_probe` route declaring a pydantic body model with a required `int` field When a client posts a body with a non-integer value (or no body) Then the response is 422 with `error.code == "validation_error"`, `error.details.errors` a non-empty list, and no 500 occurs.
AC4. Given an app from `create_app()` on which the test has registered a throwaway route that raises `ApiError(418, "teapot", "short and stout", {"size": "small"})` When a client calls it Then the response has status 418 and body `{"error": {"code": "teapot", "message": "short and stout", "details": {"size": "small"}}}`; and a route raising `ApiError(409, "conflict", "msg")` returns `details == {}`.
AC5. Given no environment variables When `Settings()` is constructed Then `max_upload_bytes == 10 * 1024 * 1024`, `allowed_content_types == ("application/pdf", "image/jpeg", "image/png")`, `ocr_backend == "fake"`, `extractor_backend == "fake"`; and Given `Settings.from_env({"APP_MAX_UPLOAD_BYTES": "1024", "APP_OCR_BACKEND": "anthropic", "ANTHROPIC_API_KEY": "k"})` Then `max_upload_bytes == 1024`, `ocr_backend == "anthropic"`, `anthropic_api_key == "k"`, and `Settings.from_env({"APP_MAX_UPLOAD_BYTES": "abc"})` raises `pydantic.ValidationError`.

## Test plan
- File: `tests/test_T-001_skeleton.py`. Build every app with `create_app()` and `fastapi.testclient.TestClient`; never import the module-level `app`.
- AC1: happy path body and status; edge: `Content-Type` is `application/json`; failure: `HEAD /healthz` is not required, skip.
- AC2: happy: `GET /nope` envelope shape checked key-by-key; edge: nested unknown path `/a/b/c`; failure path: `POST /healthz` -> 405 `method_not_allowed`.
- AC3: register `@app.post("/_probe")` with `class Body(BaseModel): n: int` on the app instance before the first request (handlers registered by `create_app` apply to routes added afterwards). Happy: `{"n": "x"}` -> 422; edge: empty body -> 422; failure path: `{"n": 1}` -> 200 to prove the route itself works.
- AC4: register a route raising `ApiError`; check status, code, message, details; edge: `details` omitted -> `{}`; failure path: `ApiError` raised inside a dependency behaves the same.
- AC5: defaults, `from_env` mapping with an explicit dict (never mutate `os.environ`), invalid int raises; edge: `from_env({})` equals `Settings()`; `Settings` is frozen (`settings.max_upload_bytes = 1` raises).
- No fixtures beyond a `client` factory; no network, no API key.
