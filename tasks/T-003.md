# T-003: Text extraction behind the OcrEngine protocol

Status: in_progress
Depends on: T-002

## Goal
A client can call `POST /documents/{id}/text` and get the document's raw text plus where it came from: the PDF text layer when it is present and substantial, otherwise the injected OCR engine; an engine failure is a 422 envelope, never a 500.

## Scope
In:
- `src/app/ocr.py`: `OcrError`, `OcrEngine` protocol, `FakeOcrEngine`, `build_ocr_engine()`.
- `src/app/models.py`: `TextExtraction`.
- `src/app/text_extraction.py`: `pdf_text_layer()`, `extract_text()` with pdf-first routing and the thin-layer fallback.
- `src/app/api.py`: `POST /documents/{id}/text`.
- `create_app(..., ocr_engine=None)` keyword; `None` -> `build_ocr_engine(settings)`; stored on `app.state.ocr_engine`.
- `tests/test_T-003_text_extraction.py`.
Out:
- Any real OCR/vision engine (T-007). `build_ocr_engine` raises `ValueError` for `"anthropic"` until then.
- Field extraction and any LLM call (T-004).
- Caching extracted text; page-level results; PDF image rendering.

```python
# src/app/ocr.py
from typing import Protocol

class OcrError(Exception):
    """Raised by extract_text() when the engine fails; wraps the original as __cause__."""

class OcrEngine(Protocol):
    def extract_text(self, content: bytes, content_type: str) -> str: ...

class FakeOcrEngine:
    def __init__(self, text: str = "", *, error: Exception | None = None) -> None: ...
    calls: list[str]        # content_type of each call, in order (never the bytes)
    def extract_text(self, content: bytes, content_type: str) -> str:
        """Appends content_type to calls; raises `error` if set; else returns `text`."""

def build_ocr_engine(settings: Settings) -> OcrEngine:
    """'fake' -> FakeOcrEngine(). Any other backend -> ValueError (until T-007)."""
```

```python
# src/app/text_extraction.py
def pdf_text_layer(content: bytes) -> str:
    """Joins pypdf page.extract_text() for every page with "\n".
    Returns "" if pypdf raises for any reason (corrupt PDF, encrypted, etc.)."""

def extract_text(
    document: StoredDocument, engine: OcrEngine, *, min_pdf_text_chars: int
) -> TextExtraction:
    """application/pdf: text = pdf_text_layer(content); if len(text.strip()) >= min_pdf_text_chars
    -> TextExtraction(source="pdf_text_layer"), engine NOT called.
    Otherwise (thin/empty layer, or any image type): engine.extract_text(content, content_type)
    -> TextExtraction(source="ocr"). Any exception from the engine is re-raised as OcrError."""
```

`Settings.min_pdf_text_chars` (default 20) is the thin-layer threshold.

Endpoints (T-003):

| Method | Path                    | Response |
|--------|-------------------------|----------|
| POST   | /documents/{id}/text    | 200 `{"document_id": str, "text": str, "source": "pdf_text_layer" \| "ocr", "char_count": int}` |

Errors (envelope): 404 `document_not_found` with `details.document_id`; 422 `ocr_failed` with
`details.reason` = exception class name of the engine's error (e.g. `"RuntimeError"`). The
`reason` never contains document bytes or text.

## Acceptance criteria
AC1. Given `create_app(ocr_engine=FakeOcrEngine("SHOULD NOT BE USED"))` and an uploaded PDF whose text layer contains `Provider: Jane Doe License: LCSW-12345 State: CA` When a client posts to `/documents/{id}/text` Then the response is 200 with `source == "pdf_text_layer"`, `text` containing `Jane Doe`, `char_count == len(text)`, and the fake engine's `calls` list is empty.
AC2. Given `create_app(ocr_engine=FakeOcrEngine("ocr text from vision"))` and an uploaded blank PDF (empty text layer) When a client posts to `/documents/{id}/text` Then the response is 200 with `source == "ocr"`, `text == "ocr text from vision"`, and `engine.calls == ["application/pdf"]`; and Given `Settings(min_pdf_text_chars=100)` and a PDF whose text layer has fewer than 100 characters Then the engine is used as well.
AC3. Given `create_app(ocr_engine=FakeOcrEngine("png text"))` and an uploaded PNG When a client posts to `/documents/{id}/text` Then the response is 200 with `source == "ocr"`, `text == "png text"`, `char_count == 8`, and `engine.calls == ["image/png"]`.
AC4. Given `create_app(ocr_engine=FakeOcrEngine(error=RuntimeError("vision down")))` and an uploaded PNG When a client posts to `/documents/{id}/text` Then the response is 422 with `error.code == "ocr_failed"`, `error.details == {"reason": "RuntimeError"}`, and the message does not contain the document bytes.
AC5. Given an app from `create_app()` When a client posts to `/documents/missing/text` Then the response is 404 with `error.code == "document_not_found"` and `error.details == {"document_id": "missing"}`; and `build_ocr_engine(Settings())` returns a `FakeOcrEngine` while `build_ocr_engine(Settings(ocr_backend="anthropic"))` raises `ValueError`.
AC6. Given `create_app(ocr_engine=FakeOcrEngine("fallback"))` and an uploaded file with bytes `b"%PDF-1.4 garbage"` declared `application/pdf` (passes the signature check, unreadable by pypdf) When a client posts to `/documents/{id}/text` Then the response is 200 with `source == "ocr"` and `text == "fallback"`; and `pdf_text_layer(b"%PDF-1.4 garbage")` returns `""`.

## Test plan
- File: `tests/test_T-003_text_extraction.py`. Use `minimal_pdf(text)` and the blank-PDF builder from SPEC section 10 as input fixtures; PNG bytes `b"\x89PNG\r\n\x1a\n" + b"\x00" * 32`.
- Helper `upload(client, name, data, ctype) -> id` posting to `/documents` and asserting 201.
- AC1: happy pdf text layer; edge: `extract_text(StoredDocument(...), engine, min_pdf_text_chars=20)` called directly returns the same `TextExtraction`; failure path: engine `calls` stays empty even after two requests.
- AC2: happy blank PDF -> engine; edge: threshold via `Settings(min_pdf_text_chars=100)` with a ~60-char text layer -> `source == "ocr"`; failure path: engine returning `""` still yields 200 with `text == ""`, `char_count == 0`.
- AC3: happy PNG; edge: JPEG (`b"\xff\xd8\xff\xe0" + b"\x00" * 32`) -> `calls == ["image/jpeg"]`; failure path: two calls on the same document call the engine twice (no caching).
- AC4: happy 422 envelope; edge: engine raising a custom exception class `class VisionDown(Exception)` -> `reason == "VisionDown"`; failure path: `extract_text` called directly raises `OcrError` whose `__cause__` is the original.
- AC5: happy 404; edge: `POST /documents/{id}/text` on a valid id but with `GET` method -> 405 envelope; failure path: `build_ocr_engine` ValueError.
- AC6: happy corrupt PDF falls back; edge: `pdf_text_layer` on a blank PDF returns `""`; failure path: corrupt PDF + engine error -> 422 `ocr_failed`, never 500.
- Fixtures: `engine` (`FakeOcrEngine`) injected via `create_app(ocr_engine=engine)`. No network, no API key.
