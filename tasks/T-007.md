# T-007: Real Anthropic adapters selected by settings

Status: in_progress
Depends on: T-005

## Goal
With `APP_OCR_BACKEND=anthropic APP_EXTRACTOR_BACKEND=anthropic ANTHROPIC_API_KEY=…`, the service uses Claude vision for OCR and Claude for field extraction; without a key the app fails fast at startup, and every adapter test that needs the network skips when the key or sample document is absent.

## Scope
In:
- `src/app/anthropic_adapters.py`: `OCR_PROMPT`, `EXTRACTION_PROMPT`, `response_text()`, `AnthropicOcrEngine`, `AnthropicFieldExtractor`, `parse_extraction_json()`, `make_client()`.
- `build_ocr_engine` / `build_field_extractor` gain the `"anthropic"` branch (lazy import of `anthropic_adapters`).
- `tests/test_T-007_anthropic_adapters.py`: stub-client tests (no network) plus live tests marked `skipif`.
Out:
- Retries, rate limiting, streaming, prompt caching, cost controls.
- Changing the pypdf-first PDF routing (it lives in T-003 `extract_text`; this engine receives a PDF only when its text layer was empty or thin).
- Adding sample documents to the repo (the human places them; see SPEC A15).
- Any change to validation rules or the response shape.

## Interface (copied from docs/SPEC.md so the ticket is self-contained)

```python
# src/app/anthropic_adapters.py
from typing import Any
import anthropic

OCR_PROMPT: str          # "Transcribe all text in this document verbatim…"
EXTRACTION_PROMPT: str   # asks for JSON with the four FIELD_NAMES, each {value,status,raw,issues}

def response_text(message: Any) -> str:
    """Concatenates block.text for every block in message.content with block.type == "text"."""

class AnthropicOcrEngine:
    def __init__(self, client: Any, model: str, *, max_tokens: int = 4096) -> None:
        """client: anthropic.Anthropic or any object exposing messages.create(**kwargs)."""
    def extract_text(self, content: bytes, content_type: str) -> str:
        """One messages.create call. image/jpeg|image/png -> content block
        {"type": "image", "source": {"type": "base64", "media_type": content_type, "data": b64}};
        application/pdf -> {"type": "document", "source": {"type": "base64",
        "media_type": "application/pdf", "data": b64}}; followed by {"type": "text", "text": OCR_PROMPT}.
        Other content types -> OcrError. Any exception from the client -> OcrError."""

class AnthropicFieldExtractor:
    def __init__(self, client: Any, model: str, *, max_tokens: int = 1024) -> None: ...
    def extract_fields(self, text: str) -> ExtractionResult:
        """One messages.create call with EXTRACTION_PROMPT + the text; returns
        parse_extraction_json(response_text(message)). Client exceptions -> ExtractorError."""

def parse_extraction_json(text: str) -> ExtractionResult:
    """Strips optional ``` / ```json fences and surrounding whitespace, json.loads.
    Top level must be an object, else ExtractorError. For each name in FIELD_NAMES:
      missing or non-object -> FieldResult(status=not_found)
      status not in FieldStatus -> status unreadable, issues + ["unknown_status"]
        (FieldResult then nulls `value` per A8, so the model's claimed value does not survive)
      value/raw non-string and not None -> str(); issues non-list -> []
    Malformed JSON -> ExtractorError."""

def make_client(settings: Settings) -> anthropic.Anthropic:
    """anthropic.Anthropic(api_key=settings.anthropic_api_key); ValueError if key is None/empty."""
```

`build_ocr_engine` (src/app/ocr.py) / `build_field_extractor` (src/app/extraction.py) gain the
branch: `"anthropic"` -> `AnthropicOcrEngine(make_client(settings), settings.anthropic_model)` /
`AnthropicFieldExtractor(make_client(settings), settings.anthropic_model)`. With
`anthropic_api_key` unset this raises `ValueError` from `create_app` (fail fast at startup).
Selecting the backend at runtime: `APP_OCR_BACKEND=anthropic APP_EXTRACTOR_BACKEND=anthropic
ANTHROPIC_API_KEY=…`. The model id defaults to `Settings.anthropic_model` (`claude-sonnet-5`,
overridable with `APP_ANTHROPIC_MODEL`).

`messages.create` is called with keyword arguments `model`, `max_tokens`, `messages` where
`messages == [{"role": "user", "content": [<blocks>]}]`. The returned message exposes
`.content`, a list of blocks each with `.type` and (for text blocks) `.text`.

## Acceptance criteria
AC1. Given `AnthropicOcrEngine(stub, "model-x")` where `stub.messages.create(**kwargs)` records `kwargs` and returns a message whose `content` is one text block `"hello from vision"` When `extract_text(<PNG bytes>, "image/png")` is called Then it returns `"hello from vision"`, exactly one call was made with `model == "model-x"`, `messages[0]["role"] == "user"`, the first content block is `{"type": "image", "source": {"type": "base64", "media_type": "image/png", "data": base64.b64encode(<PNG bytes>).decode()}}`, and the last block is a text block equal to `OCR_PROMPT`.
AC2. Given the same stub When `extract_text(<PDF bytes>, "application/pdf")` is called Then the first content block is `{"type": "document", "source": {"type": "base64", "media_type": "application/pdf", "data": <b64>}}`; When `extract_text(b"x", "text/plain")` is called Then `OcrError` is raised without calling the stub; and When the stub raises `RuntimeError` Then `OcrError` is raised with that error as `__cause__`.
AC3. Given `parse_extraction_json` When given a fenced response ```` ```json {"provider_name": {"value": "Jane Doe", "status": "found", "raw": "Jane Doe", "issues": []}, "state": {"value": "CA", "status": "maybe"}} ``` ```` Then the result has `provider_name` found with value `Jane Doe`, `state` with `status == "unreadable"`, `value is None`, `issues == ["unknown_status"]`, `license_number` and `expiration_date` `not_found`, and `missing_fields == ["license_number", "state", "expiration_date"]`; When given `"not json"` or `"[1, 2]"` Then `ExtractorError` is raised.
AC4. Given `AnthropicFieldExtractor(stub, "model-x")` whose stub returns a text block with a valid four-field JSON When `extract_fields("License text")` is called Then the returned `ExtractionResult` matches the JSON, one call was made with `model == "model-x"` and a user message whose text contains both `EXTRACTION_PROMPT` and `"License text"`; and When the stub raises `RuntimeError` Then `ExtractorError` is raised.
AC5. Given `Settings(ocr_backend="anthropic", extractor_backend="anthropic", anthropic_api_key=None)` When `create_app(settings)` is called Then `ValueError` is raised; and Given the same settings with `anthropic_api_key="test-key"` When `create_app(settings)` is called Then `app.state.ocr_engine` is an `AnthropicOcrEngine` and `app.state.field_extractor` is an `AnthropicFieldExtractor` (no network call is made by construction).
AC6. Given `ANTHROPIC_API_KEY` is set in the environment (otherwise the test is skipped) When `AnthropicFieldExtractor(make_client(Settings.from_env()), Settings.from_env().anthropic_model).extract_fields("Licensed Clinical Social Worker. Name: Jane Q. Doe. License No. LCSW-12345. State of California. Expires: 12/31/2099")` is called and the result is passed through `validate_result(..., today=date.today())` Then all four fields are `found`, `state.value == "CA"`, `expiration_date.value == "2099-12-31"`, and `missing_fields == []`; and Given additionally `tests/fixtures/sample_license.png` exists (otherwise skipped) When `AnthropicOcrEngine(...).extract_text(<its bytes>, "image/png")` is called Then a non-empty string is returned.

## Test plan
- File: `tests/test_T-007_anthropic_adapters.py`.
- Stub client (a fixture that builds an input, not the behavior under test): a small class with `messages.create(**kwargs)` that appends `kwargs` to a list and returns `types.SimpleNamespace(content=[types.SimpleNamespace(type="text", text=<canned>)])`; a variant raising a configured exception.
- AC1: happy PNG block shape; edge: JPEG uses `media_type == "image/jpeg"`; tolerance case: a message with zero text blocks returns `""`.
  (Corrected during T-007: that last case is tolerance, not a failure path. AC1 has no true error case -- both OCR error paths, unsupported type and a raising client, are under AC2.)
- AC2: happy PDF document block; edge: message with two text blocks is concatenated by `response_text`; failure path: unsupported type raises before any call (`calls == []`).
- AC3: happy fenced JSON with unknown status; edge: bare JSON without fences and with `"issues": "oops"` (non-list -> `[]`) and `"value": 12345` (-> `"12345"`); failure path: `"not json"` and `"[1, 2]"` raise `ExtractorError`.
- AC4: happy round trip; edge: response with leading prose before the fence is still parsed only if the whole text after fence stripping is JSON — assert prose + fence raises `ExtractorError` (documented limitation); failure path: client exception -> `ExtractorError` with `__cause__`.
- AC5: happy `make_client(settings)` raises `ValueError` when the key is missing; edge: `make_client(Settings(anthropic_api_key=""))` raises `ValueError`; failure path: `ocr_backend="anthropic"` with `extractor_backend="fake"` builds `AnthropicOcrEngine` and `FakeFieldExtractor`.
  (Corrected during T-007: asserting only that `create_app(Settings(ocr_backend="anthropic", anthropic_api_key=None))` raises `ValueError` is vacuous -- `build_ocr_engine` already raises for any non-"fake" backend since T-003, so it passed before this ticket existed. The test must also call `make_client` so it distinguishes a missing key from an unknown backend name.)
- AC6: `pytest.mark.skipif(not os.environ.get("ANTHROPIC_API_KEY"), reason="needs ANTHROPIC_API_KEY")`; the OCR live test additionally skips when `tests/fixtures/sample_license.png` is missing. These are the only tests in the suite allowed to touch the network. Do not print or assert on the key.
- Fixtures: `stub_client` factory; `Settings(...)` instances constructed explicitly (never read `os.environ` except in AC6).
